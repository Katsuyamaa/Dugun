# Düğün Davetiyesi

Çağla & Tunahan'ın düğünü için hazırlanmış, tek sayfalık dijital düğün davetiyesi. Giriş videosu, müzik ve animasyonlu bölümler içerir; Vercel üzerinde yayınlanır.

## Teknolojiler

- HTML, CSS, vanilla JavaScript (tek dosya, framework yok)
- Google Fonts (Playfair Display, Cormorant Garamond, Great Vibes, Cinzel Decorative)
- Vercel (statik hosting, medya için özel header ayarları)

## Nasıl Çalıştırır

Herhangi bir statik dosya sunucusuyla açılabilir:
```
npx serve .
```
veya `index.html` dosyasını doğrudan tarayıcıda açabilirsiniz.

## Öne Çıkan Özellikler

- Tıkla-aç giriş videosu ve arka plan müziği
- Sosyal medya paylaşımı için Open Graph / Twitter kart meta verileri
- Mobil uyumlu, tek sayfa akıcı tasarım
- Özel görsel ve ses varlıkları (`Image/`, `Music/`)
